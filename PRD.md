# PRD: Анализ единичных повреждений

## Проблема

Ежемесячно вручную анализируются выгрузки заявок по единичным повреждениям (медь/GPON) из Qlik Sense: сведение в сводные таблицы, расчёт показателей, подготовка презентации для руководства — трудоёмко и повторяется из месяца в месяц. Часть рабочих компьютеров использует устаревшие версии Office (PowerPoint 2003) без пакета совместимости, что ограничивает выбор формата отчёта.

## Цель

Инструмент, который по загруженной выгрузке `.xlsx` за один прогон считает показатели, сравнивает с предыдущим месяцем и собирает готовые файлы для отчётности — без ручной сборки таблиц и слайдов, без установки ПО и без интернета.

## Пользователь

Один человек (начальник участка), готовит ежемесячный отчёт для руководства. Работает как минимум на одном ПК со старой версией Office.

## Входные данные

- Выгрузка единичных повреждений за отчётный месяц (`.xlsx` или `.csv`), опционально — за предыдущий месяц для сравнения.
- Файл содержит уже только единичные повреждения (без массовых) — фильтрация на входе не требуется.
- Названия столбцов могут отличаться от файла к файлу — соответствие полям определяется автоматически с возможностью ручной правки.

## Функциональные требования

### Сопоставление данных
- Автоматическое распознавание столбцов по названию: дата регистрации и устранения (обязательные), технология, участок, исполнитель, причина, тип повреждения, статус, номер заявки, услуга, адрес/абонент (необязательные).
- Ручная корректировка сопоставления перед расчётом.

### Расчёт показателей
- Объём повреждений, устранено/не устранено.
- Устранение в контрольный срок (норматив настраивается, по умолчанию 8 ч) и «длительное устранение» сверх него (влияет на показатель «Доступность сети доступа»).
- Устранение в день подачи с учётом переноса заявок, поступивших после отсечки (по умолчанию 17:00), на следующий рабочий день.
- Выполнение норматива по GPON в день подачи (план настраивается, по умолчанию 85%).
- Среднее и медианное время устранения, распределение по интервалам.
- Период отчёта определяется по преобладающему месяцу в выгрузке (устойчиво к единичным заявкам с датой вне месяца).

### Срезы
- По технологиям, участкам, исполнителям, причинам.
- По типу повреждения (терминальное / кабельное / линейно-абонентское / станционно-абонентское / WLL / абонентское / другое) с долей каждого типа.
- Переходящие vs устранённые в день подачи.

### Повторные обращения
- Абоненты с 2 и более обращениями за период.
- Особый контроль — абоненты с N и более обращениями (порог настраивается, по умолчанию 3), со списком адресов и дат обращений.

### Сравнение периодов
- Все ключевые показатели — с динамикой к предыдущему месяцу (если загружен второй файл).

### Экспорт
- **Презентация (PPTX)** — диаграммы по каждому срезу, пояснения к слайдам в заметках докладчика.
- **Отчёт (Word, .rtf)** — тот же материал в виде текста и таблиц; открывается в любой версии Office, включая PowerPoint/Word 2003 без пакета совместимости.
- **Сводные таблицы (Excel)** — отдельные листы по каждому срезу, включая полный список повторных обращений.

## Настраиваемые параметры

Контрольный срок устранения (ч), план по GPON (%), отсечка переноса на следующий день (ч), суббота — рабочий день (вкл/выкл), порог особого контроля (число обращений), название подразделения для титульного слайда.

## Технические ограничения и решения

- Работает как один HTML-файл, открывается локально, без сервера и без интернета после загрузки страницы.
- Чтение/запись `.xlsx`, запись `.pptx` и `.rtf` реализованы без внешних библиотек — во избежание зависимости от CDN, которая ранее приводила к невозможности собрать презентацию офлайн.
- Не поддерживается старый бинарный `.xls` — только `.xlsx`/`.csv`.
- Для чтения сжатых `.xlsx` нужен браузер с поддержкой Compression Streams API (актуальные версии Chrome/Edge/Firefox/Safari).

## Вне объёма

- Хранение истории отчётов между запусками (данные не сохраняются между сессиями).
- Многопользовательский доступ и совместная работа.
- Автоматическая выгрузка из Qlik Sense — файл загружается вручную.
